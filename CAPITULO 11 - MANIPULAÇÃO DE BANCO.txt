Design patterns, ou padrões de projeto, são soluções reutilizáveis para problemas comuns que surgem durante o desenvolvimento de software. Representando as melhores práticas desenvolvidas ao longo do tempo por desenvolvedores experientes, esses padrões oferecem uma abordagem sistemática para resolver desafios recorrentes de design de software.

Em essência, padrões de projetos fornecem um conjunto de diretrizes testadas e aprovadas, capacitando os desenvolvedores a criarem sistemas mais robustos, flexíveis e fáceis de manter.

PADRÕES DE PROJETO(DESIGN PETTERNS)

* Uma Connection Factory é um padrão de projeto que cuida da criação de objetos de conexão com o banco de dados.

Sua principal função é ocultar os detalhes complexos envolvidos na criação e configuração dessas conexões, oferecendo uma interface simplificada para o restante do código da aplicação solicitar e receber conexões sem precisar entender os detalhes específicos de implementação. Além disso, ela pode administrar vários aspectos da conexão com o banco de dados, como a URL de conexão, as credenciais de autenticação, as propriedades de conexão e até mesmo o pool de conexões, visando promover modularidade, reutilização de código e a manutenção mais fácil do sistema.

* O padrão DAO é como um intermediário entre nossa aplicação e a fonte de dados, como um banco de dados. Ele ajuda a manter as coisas organizadas, isolando a lógica de acesso aos dados em classes separadas. Essas classes fornecem métodos simples para interagir com os dados, como adicionar, recuperar, atualizar ou excluir registros (CRUD).

Basicamente, o DAO nos permite acessar os dados de maneira fácil e consistente em toda a aplicação. Isso significa que, se precisarmos mudar a forma como os dados são armazenados, como mudar de um banco de dados relacional para um banco de dados NoSQL, por exemplo, podemos fazer isso sem afetar o resto da nossa aplicação. O padrão DAO nos ajuda a manter nosso código organizado, modular e fácil de manter, separando as preocupações relacionadas ao acesso aos dados das preocupações relacionadas à lógica de negócio.
